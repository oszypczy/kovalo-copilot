# reference/course: kod referencyjny kursu (tylko do odczytu)

Kopia kodu z repozytorium kursu [wodecki/TEG_PL_Project_2026](https://github.com/wodecki/TEG_PL_Project_2026), stan z 2026-11-01, bez folderu `data/`, który leży w `/data`.

Do czego go używamy:
- szkielety kroków (`mini_project_*/src/step*.py`) opisują w docstringach kontrakty (CEL / WYNIK / WYMAGANIA), które nasza implementacja ma spełnić,
- testy (`mini_project_*/tests/`) pokazują oczekiwane zachowanie i przypadki brzegowe,
- `helpers/` zawiera gotową logikę ewaluacji (ocena trace, liczby po polsku, ewaluacja asystenta), którą przenosimy albo adaptujemy w `src/kovalo/eval/`.

Tego kodu nie uruchamiamy i nie importujemy z `src/`. Nie edytuj go.
